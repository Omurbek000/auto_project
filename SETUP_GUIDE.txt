=== НАСТРОЙКА EMAIL И SMS ===

Все настройки в файле .env (в корне проекта).

=============================================
  1. EMAIL (SMTP)
=============================================

Где взять:
┌────────────────────┬──────────────────────────────────────────────┐
│ Сервис             │ Инструкция                                  │
├────────────────────┼──────────────────────────────────────────────┤
│ Gmail              │ 1. Зайди https://myaccount.google.com/      │
│                    │ 2. Безопасность → 2-этапная аутентификация  │
│                    │ 3. Пароли приложений → создать              │
│                    │ 4. Скопировать пароль (16 букв)             │
│                    │                                            │
│ Yandex             │ 1. Зайди https://mail.yandex.ru/           │
│                    │ 2. Настройки → Почтовые программы          │
│                    │ 3. Включить "С сервера imap.yandex.ru"     │
│                    │ 4. Создать пароль приложения               │
│                    │                                            │
│ Mail.ru            │ 1. Зайди https://e.mail.ru/settings        │
│                    │ 2. Почтовые программы → создать пароль     │
└────────────────────┴──────────────────────────────────────────────┘

Что вписать в .env:
    EMAIL_HOST=smtp.gmail.com
    EMAIL_PORT=587
    EMAIL_HOST_USER=твой_email@gmail.com
    EMAIL_HOST_PASSWORD=твой_пароль_приложения
    DEFAULT_FROM_EMAIL=твой_email@gmail.com

Для Gmail: smtp.gmail.com
Для Yandex: smtp.yandex.ru
Для Mail.ru: smtp.mail.ru


=============================================
  2. SMS (Twilio)
=============================================

Где взять:
┌──────────────────────────────────────────────────────────────────┐
│ 1. Зарегистрируйся https://www.twilio.com/try-twilio           │
│ 2. Подтверди email и телефон                                   │
│ 3. В консоли Twilio скопируй:                                  │
│    - Account SID (в дашборде)                                  │
│    - Auth Token (в дашборде)                                   │
│ 4. Купи номер (или используй пробный):                         │
│    Navigation → Phone Numbers → Buy a Number                   │
│ 5. В настройках номера разреши SMS                            │
└──────────────────────────────────────────────────────────────────┘

Что вписать в .env:
    TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    TWILIO_PHONE_NUMBER=+1234567890


=============================================
  3. КАК ЭТО РАБОТАЕТ В КОДЕ
=============================================

Если переменные пустые → всё работает как раньше (вывод в консоль)
Если переменные заполнены → реальная отправка

Проверить email:
    python -c "
    import django, os
    os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'avto.settings')
    django.setup()
    from project.services import send_email
    send_email('Тест', 'Проверка связи', ['твой_email@gmail.com'])
    "

Проверить SMS:
    python -c "
    import django, os
    os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'avto.settings')
    django.setup()
    from project.services import send_sms
    send_sms('+71234567890', 'Тестовое SMS')
    "


=============================================
  4. КОГДА EMAIL И SMS ОТПРАВЛЯЮТСЯ
=============================================

SMS:
- Новый запрос аренды → владельцу
- Аренда подтверждена → арендатору
- Аренда отклонена → арендатору
- Новое сообщение в чате → получателю

Email:
- Всё то же самое, что и SMS (дублируется)
- Код сброса пароля
- Код верификации email
