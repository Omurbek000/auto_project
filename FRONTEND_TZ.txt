=== ТЕХНИЧЕСКОЕ ЗАДАНИЕ НА ФРОНТЕНД (REACT + GLASSMORPHISM) ===

Стиль: Nixon SaaS — тёмная тема + glassmorphism (эффект матового стекла)
Референс: https://dribbble.com/shots/21677009-Nixon-SaaS-Web-Log-in-Screen

=============================================
  1. ОБЩИЙ СТИЛЬ
=============================================
- Фон: градиент от фиолетового к синему (#6C63FF → #4F8CFF) на тёмном фоне
- Карточки: полупрозрачные стеклянные края (glass edges)
- Размытие: backdrop-filter: blur(20px)
- Рамки: тонкие, полупрозрачные (border: 1px solid rgba(255,255,255,0.1))
- Тень: box-shadow с размытием + шкала высот (elevation scale)
- Текст: белый / светло-серый
- Акцент: фиолетово-синий градиент
- Скругления: 12-16px
- Иконки: Outline-стиль (Lucide React или Heroicons)
- Типография: уверенная, современная (Inter или SF Pro)
- Сетка: 8-точечная система (8, 16, 24, 32px и тд)
- Доступность: WCAG AA для тёмной темы (контрастные цвета, состояния фокуса)

=============================================
  2. СТРАНИЦЫ
=============================================

--- 2.1. ЛОГИН / РЕГИСТРАЦИЯ ---
- Центрированная карточка на весь экран
- Слева: логотип + описание сервиса
- Справа: форма (email, пароль, кнопка входа)
- Эффект частиц/градиента на фоне
- После входа:
  * Админ → редирект на /admin/dashboard/
  * Владелец → редирект на /owner/stats
  * Арендатор → редирект на /

--- 2.2. ГЛАВНАЯ (поиск машин) ---
- Шапка: лого + навигация + профиль (с выпадающим меню)
- Hero-блок: поле поиска (город, даты, кнопка найти)
- Сетка карточек автомобилей в стиле glass
- Каждая карточка: фото, марка, цена, рейтинг, кнопка
- Пагинация / бесконечная подгрузка

--- 2.3. ДЕТАЛЬНАЯ СТРАНИЦА МАШИНЫ ---
- Галерея фото (главное + доп. фото)
- Информация: описание, характеристики, цена
- Календарь доступности (подсвечены занятые даты)
- Кнопка "Забронировать"
- Блок с отзывами

--- 2.4. ЛИЧНЫЙ КАБИНЕТ ПОЛЬЗОВАТЕЛЯ / ДАШБОРД ---
- Боковое меню (glass-стиль, полупрозрачное)
- Пункты: Мои аренды, Избранное, Мои машины, Статистика, Настройки
- Карточки KPI (данные из /analytics/):
  * Доход от аренды (revenue_total, только owner)
  * Сдаваемость машин (cars_rental_days: сколько дней каждая машина сдавалась, без цены)
  * Аренды по статусам (rentals_by_status)
  * Каждая карточка с микрографиком (спарклайн из revenue_by_month) и ежемесячным изменением
  * Зелёный ↑ — рост, Красный ↓ — падение
- Журнал операций (таблица "Недавняя активность"):
  * Дата, тип операции, статус, сумма (своих операций)
  * Возможность экспорта (CSV/Excel/PDF)
  * Подчёркивает возможность аудита
- Аналитика:
  * Круговая диаграмма: машины по брендам (cars_by_brand)
  * График дохода по месяцам (revenue_by_month, только owner)
  * Сдаваемость по машинам (cars_rental_days, только owner)
  * Модуль быстрой передачи данных (выгрузить отчёт)
- Экспорт данных:
  * Кнопка "Экспорт" на всех таблицах
  * Форматы: CSV, Excel, PDF
  * Выгрузка отчётов за период

--- 2.5. ДАШБОРД АДМИНА (управление через фронт) ---
- Навигация: Дашборд, Пользователи, Отзывы, Жалобы, Аудит
- Карточки KPI со сводкой (данные из /admin/analytics/):
  * Всего пользователей, машин, аренд
  * Активные аренды, ожидающие подтверждения (pending_rentals)
  * Ожидающие жалобы (pending_complaints)
  * Каждая с микрографиком (спарклайн из rentals_by_month) и динамикой
- Журнал операций всей платформы:
  * Детальная таблица со статусами (без сумм — финансы анонимны)
  * Экспорт в CSV/Excel/PDF
- Аналитика:
  * Круговая диаграмма: распределение машин по брендам (cars_by_brand)
  * График количества аренд по месяцам (rentals_by_month)
  * Топ машин по сдаваемости (top_cars_by_days, без цены)
- Управление пользователями:
  * Список всех пользователей
  * Блокировка / верификация
  * Назначение ролей
  * История активности пользователя
- Управление жалобами:
  * Список со статусами (pending/reviewing/resolved/rejected)
  * Ответ админа через форму
  * Смена статуса
- Аудит: логирование всех действий администратора
- Админ НЕ модерирует машины и аренды: это права владельца. Владелец сам
  подтверждает/отменяет аренды своих машин и управляет своими машинами.
  Пунктов «Машины» и «Аренды» в навигации админа нет.

--- 2.6. ЧАТ ---
- Слева: список чатов (glass-карточки с последним сообщением)
- Справа: переписка (облака сообщений)
- Поле ввода с кнопкой отправить
- Отметка о прочтении

--- 2.7. ПРОФИЛЬ / НАСТРОЙКИ ---
- Аватар (с возможностью загрузить)
- Форма редактирования (имя, телефон, почта, права)
- Настройки: стать владельцем (is_owner), верификация email/телефона
- Смена пароля

=============================================
  3. ТЕХНОЛОГИИ (РЕКОМЕНДУЮ)
=============================================
- React + Vite (быстрая сборка)
- React Router (навигация)
- Axios (запросы к API)
- Tailwind CSS (стили + 8-точечная сетка)
- Framer Motion (анимации)
- Lucide React (иконки)
- Recharts (графики, диаграммы, спарклайны)
- React Calendar / DatePicker (календарь)
- React Table / TanStack Table (таблицы с сортировкой)
- xlsx / jspdf (экспорт в Excel/PDF)
- React Hook Form (формы)

=============================================
  4. ЦВЕТОВАЯ ПАЛИТРА (WCAG AA)
=============================================
- Фон: #0a0a1a → #1a1a2e (градиент)
- Карточки: rgba(255, 255, 255, 0.05) + blur(20px)
- Текст основной: #ffffff
- Текст второстепенный: rgba(255, 255, 255, 0.7)
- Акцент: #6C63FF → #4F8CFF (фиолетово-синий градиент)
- Успех: #10B981 (зелёный)
- Ошибка: #EF4444 (красный)
- Предупреждение: #F59E0B (жёлтый)
- Рамки: rgba(255, 255, 255, 0.1)
- Ховер: rgba(255, 255, 255, 0.1)
- Фокус: кольцо с акцентным цветом (focus-visible)

=============================================
  5. МАРШРУТЫ (ROUTES)
=============================================
/                   — Главная (поиск машин)
/login              — Вход
/register           — Регистрация
/car/:id            — Детальная страница машины
/profile            — Профиль / Настройки
/rentals            — Мои аренды
/favorites          — Избранное
/my-cars            — Мои машины (owner)
/owner/stats        — Статистика владельца (KPI + графики)
/chat               — Список чатов
/chat/:id           — Чат
/complaints         — Жалобы
/admin/dashboard    — Дашборд админа (KPI + аналитика)
/admin/users        — Управление пользователями
/admin/complaints   — Управление жалобами
/admin/audit        — Лог аудита действий админа

=============================================
  6. СИСТЕМНЫЕ ТОКЕНЫ (DESIGN SYSTEM)
=============================================
- 8-точечная сетка: отступы 8, 16, 24, 32, 40, 48px
- Шкала теней/высот (elevation): 4 уровня (card, modal, dropdown, toast)
- Состояния: hover, active, focus-visible, disabled
- Фокус: цветное кольцо с отступом 2px (focus-visible:ring)
- Семантические цвета для WCAG AA:
  * color-bg (фон)
  * color-surface (карточки)
  * color-text-primary
  * color-text-secondary
  * color-accent
  * color-success / error / warning

=============================================
  7. ФИРМЕННЫЙ СТИЛЬ (BRANDING)
=============================================
- Уверенная типография (Inter, SemiBold для заголовков)
- Изящные стеклянные края (glass edges с тонкой обводкой)
- Градиент от фиолетового к синему (современный, заслуживающий доверия)
- Минималистичные иконки в outline-стиле
- Плавные анимации при переходе между страницами (Framer Motion)

=============================================
  8. ЗАМЕТКИ
=============================================
- При входе админа редиректить сразу на /admin/dashboard/
- Все glass-карточки должны иметь:
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 16px;
- Экспорт данных — на всех страницах с таблицами (CSV, Excel, PDF)
- Аудит действий — обязательно для фин. операций и действий админа
- Микрографики (sparkline) на KPI-карточках — для быстрого анализа трендов
- Тёмная тема — строго WCAG AA (контраст текста минимум 4.5:1)
