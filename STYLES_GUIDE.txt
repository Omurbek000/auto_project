=== СПРАВОЧНИК ПО СТИЛЯМ И КОМПОНЕНТАМ ФРОНТЕНДА ===
Проект: AVTO — платформа аренды автомобилей
Технологии: React 18 + TypeScript + Vite, @tanstack/react-query,
lucide-react (иконки), recharts (графики), dayjs, react-hook-form + zod.
Все стили в ОДНОМ файле: frontend/src/index.css

ВАЖНО: в :root стоит color-scheme: dark — браузер рисует тёмные
нативные элементы (select/option, date input, скроллбары).
Это чинит проблему «белый текст на белом фоне» у выпадающих списков.

=============================================
  2. ОБЩИЙ СТИЛЬ
=============================================
- Фон body: радиальные градиенты (фиолетовый + синий) на тёмном, fixed.
- Два «светящихся шара» .orb1 / .orb2 — blur(70px), плавают через @keyframes float.
- Скругления 12–16px, стекло blur(20px), тонкие рамки rgba(255,255,255,0.1).
- Все кнопки, поля, карточки используют переменные выше.
- Шрифт: Inter, -apple-system, 'Segoe UI', Roboto, sans-serif.

=============================================
  10. ГАЛЕРЕЯ ФОТО МАШИНЫ (PhotoManager)
=============================================
Открывается из «Мои машины» → кнопка «Фото».

.photo-grid — сетка плиток (auto-fill minmax 140px; на мобильных 110px)
.photo-tile — плитка; .photo-tile.on — зелёная рамка у основного фото
.photo-tile img — превью 110px
.photo-main-tag — зелёная метка «Основное» в углу
.photo-tile-actions — кнопки «Сделать основным» / «Удалить»

Функциональность:
- Пакетная загрузка нескольких файлов (input multiple)
- Первое фото при отсутствии других автоматически становится основным
- POST /car/image/<id>/set-main/ — сменить основное
- Удаление фото; после удаления основного основным становится первое оставшееся

=============================================
  11. ЛАЙТБОКС (просмотр фото как на Wildberries)
=============================================
Клик по фото на странице машины → полноэкранное окно.

.lightbox — фиксированный слой, затемнение rgba(0,0,0,0.92), z-index 1000
.lightbox-img — фото по центру (max 92vw x 88vh, contain)
.lightbox-close — крестик сверху справа (круглая кнопка)
.lightbox-nav / .lightbox-prev / .lightbox-next — стрелки слева/справа
.lightbox-count — счётчик «N / M» снизу по центру

Управление:
- Клик по фото / превью → открыть
- Стрелки ← → на клавиатуре и кнопки по бокам → листать по кругу
- ESC или крестик или клик по затемнению → закрыть

Реализация: src/pages/CarDetailPage.tsx (состояние lightbox, useEffect
слушает клавиши), стили в index.css.

=============================================
  12. АДАПТИВНОСТЬ (брейкпоинты)
=============================================
≤1100px — контейнер уже (20px)
≤900px  — сетки в 2 колонки; детальная страница машины в 1 колонку
          (фото сверху, бронирование снизу, sticky убирается);
          экран входа в 1 колонку; чат ниже; календарь компактнее
≤768px  — контейнер 14px; верхняя панель: центральные ссылки
          скрываются (все разделы доступны в меню профиля);
          имя пользователя скрывается, только аватар;
          модалки почти на весь экран; кнопки переносятся по строкам
≤600px  — все сетки в 1 колонку; сайдбар горизонтальный
≤480px  — телефон: фото детальной страницы 240px; превью меньше;
          лайтбокс стрелки/крестик компактнее; фильтры с датами
          в столбик; тосты на всю ширину; статистика меньше
